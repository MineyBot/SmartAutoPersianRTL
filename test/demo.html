حتماً. پیاده‌سازی quicksort با روش تقسیم و حل به این شکل است:

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    p = arr[len(arr) // 2]
    lo = [x for x in arr if x < p]
    eq = [x for x in arr if x == p]
    hi = [x for x in arr if x > p]
    return quicksort(lo) + eq + quicksort(hi)

مراحل کار

  1. یک عنصر به‌عنوان محور (pivot) انتخاب می‌شود.
  2. آرایه به سه بخش کوچک‌تر، مساوی و بزرگ‌تر تقسیم می‌شود.
  3. پیچیدگی زمانی میانگین O(n log n) و بدترین حالت O(n²) است.
نکته: انتخاب محورِ تصادفی از بدترین حالت O(n²) روی داده‌ی از پیش مرتب جلوگیری می‌کند.
حالتTimeSpace
میانگینO(n log n)O(n)
بدترینO(n²)O(n)

این پیاده‌سازی در هر فراخوانی سه لیست تازه می‌سازد، پس حافظه‌اش O(n) است؛ نسخه‌ی in-place با O(log n) کار می‌کند.
